PP Editorial New (Italic) is a commercial font by Pangram Pangram, so it can't be bundled here.
Drop your licensed files in this folder using these exact names and the deck picks them up:
  PPEditorialNew-Italic.woff2        (Regular Italic)
  PPEditorialNew-UltraboldItalic.woff2
Until then, titles fall back to Playfair Display Italic (bold).
